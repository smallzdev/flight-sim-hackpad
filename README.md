## BOM

1 x Seeduno XIAO RP2040
1 x MICROCHIP MCP23017-E/SP Pin Expander
1 x 100nF 50VDC Capacitor
1 x 0.91 inch OLED display (pin order = GND-VCC-SCL-SDA)
2 x EC11E Rotary encoders (with switch)
4 x M3x16mm screws
6 x DSA keycaps
6 x MX-Style switches
1 x PCB
